# RK3588S build dependencies

Phase 1 uses the Rockchip-enabled FFmpeg build on the target board. Do not mix its headers with the Ubuntu system FFmpeg headers: FFmpeg headers and shared libraries must come from the same installation.

## Expected board layout

The adjacent AlertGateway project uses this target-board prefix:

```text
/opt/ffmpeg-rockchip
├── include/
└── lib/
```

It also uses Rockchip MPP from the board. The active EdgeSight implementation currently uses FFmpeg's `h264_rkmpp`; direct MPP is only a fallback design candidate and is not part of the current build.

## Verify the board

Run from the EdgeSight repository on the RK3588S:

```bash
scripts/preflight.sh
```

`verify_camera_capabilities.sh` reads the local configuration, saves the complete V4L2 capability output under `logs/`, and verifies that the configured C310 device advertises the Phase 1 request: MJPEG, 1280×720, 30 FPS. It does not change the active V4L2 format or FPS. If it fails, do not edit the project constraint silently: retain its log, update project memory with the measured fact, and decide the replacement baseline explicitly.

`preflight.sh` runs dependency check, camera capability check, target-board build, canonical C++ configuration validation, and the configured SRS RTMP-port connectivity check in that order. It stops at the first failing step and writes a combined log under `logs/`. It never starts, stops, or modifies SRS.

## Build

```bash
scripts/build.sh
```

The script defaults to `/opt/ffmpeg-rockchip`. For a different valid board prefix:

```bash
EDGESIGHT_FFMPEG_PREFIX=/path/to/ffmpeg scripts/build.sh
```

The executable is linked with an RPATH to that prefix, so it resolves the matching target FFmpeg libraries at runtime.

## Optional host cross-build

When `/home/rambos/sysroot` is available, use the same RK3588 sysroot layout as AlertGateway:

```bash
scripts/build_cross_rk3588.sh
file build-rk3588/edgesight_streamer
```

This produces an ARM64 binary only; it does not replace the target-board preflight or camera/SRS acceptance.

The checked-in sysroot intentionally omits some optional FFmpeg transitive dependencies. The cross-build therefore follows AlertGateway and allows unresolved shared-library references at link time; the target-board preflight remains the runtime dependency authority.
