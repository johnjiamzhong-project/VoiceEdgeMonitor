# Phase 1 acceptance: C310 to SRS

## Preconditions

1. Copy `config/config.example.yaml` to `config/config.yaml` and set the SRS host and stream key.
2. On the RK3588S target, run `scripts/preflight.sh` successfully. This performs the dependency, C310 capability, build, configuration, and SRS-port checks in the required order.

## Test

1. Run `scripts/acceptance_10min.sh` to launch a 10-minute publisher run and save its log and summary. For a short dry run only, set `EDGESIGHT_ACCEPTANCE_SECONDS=10`.
2. Open the corresponding SRS playback URL in VLC (or a known-good SRS client).
3. Watch the video continuously for the full 10 minutes.
4. Confirm that the summary reports `publisher_exit_code=0` and that the publisher log reports `stopped cleanly` after the scripted `SIGINT`.

## Pass criteria

- A 1280x720, 30 FPS C310 image is visible through SRS for the full 10 minutes.
- The program reports capture FPS, encode FPS, pushed packet count, and error count at the configured interval.
- No unplanned process exit occurs.
- `logs/acceptance-*.log` and `logs/acceptance-*.summary.txt` are retained with the test start/end time and observed result.
