# Phase 3 视觉单图 Demo

Phase 3 的第一步是把一次图片问答独立跑通，再接入视频 latest-frame 和 `asr_final`。视频推流和音频监听不进入这次单图推理调用。

## 运行时边界

当前 8GB Firefly 目标板先以 Qwen3-VL-2B 作为首轮验收方案。4B 仍保留为更大内存设备的后续方案；在本板上先加载 4B 会把内存风险带入模型验收。

板端需要一组相互匹配的文件：

```text
视觉编码器：qwen3-vl-2b-vision_rk3588.rknn
语言模型：qwen3-vl-2b-instruct_w8a8_rk3588.rkllm
运行库：librknnrt.so、librkllmrt.so
```

视觉编码器生成 image embedding，RKLLM 再结合 embedding 和文本问题生成回答。两个模型文件必须来自同一模型规格和兼容的导出/runtime 版本。模型、运行库和转换工具不放入仓库。

当前选用的外部 2B 包以 `rkllm-runtime 1.2.3` 为匹配版本；不要把 1.3.x runtime 与这组 1.2.3 模型混用。工程会自动识别旧版 RKLLM ABI。

Firefly 目标板已在隔离目录中部署成套 2B 运行库和模型，并通过 `vision_preflight.sh` 预检。运行库与模型仍保持在仓库外部；默认构建不会复制或打包这些资产。

外部 2B smoke-test 包和对应 runtime 可从 [Qengineering/Qwen3-VL-2B-NPU](https://github.com/Qengineering/Qwen3-VL-2B-NPU) 的 README 下载；下载后必须先核对文件大小和 SHA-256，再复制到目标板外部目录。

## 默认构建与图像核心测试

不需要 RKNN、RKLLM 或模型即可验证 PPM 解码和 letterbox 预处理：

```bash
cmake -S . -B /tmp/edgesight-vision-test \
  -DEDGESIGHT_BUILD_STREAMER=OFF \
  -DEDGESIGHT_BUILD_AUDIO=OFF \
  -DEDGESIGHT_BUILD_VISION=OFF \
  -DBUILD_TESTING=ON
cmake --build /tmp/edgesight-vision-test --parallel
ctest --test-dir /tmp/edgesight-vision-test --output-on-failure
```

## 启用真实 RKNN/RKLLM Demo

`RKNN_ROOT` 和 `RKLLM_ROOT` 指向外部 SDK 的根目录。CMake 会查找 `rknn_api.h`、`rkllm.h` 及对应的 ARM64 运行库；找不到任一项时直接停止配置。

```bash
cmake -S . -B /tmp/edgesight-vision-rk3588 \
  -DCMAKE_TOOLCHAIN_FILE=cmake/toolchains/rk3588.cmake \
  -DEDGESIGHT_BUILD_STREAMER=OFF \
  -DEDGESIGHT_BUILD_AUDIO=OFF \
  -DEDGESIGHT_BUILD_VISION=ON \
  -DRKNN_ROOT=/path/to/librknnrt \
  -DRKLLM_ROOT=/path/to/rkllm-runtime
cmake --build /tmp/edgesight-vision-rk3588 --parallel
```

如果使用 1.2.3 成套 runtime，`RKNN_ROOT` 和 `RKLLM_ROOT` 可以分别指向包含 `include/` 和 `library/` 的外部目录；CMake 会自动检测旧版 RKLLM ABI。

官方 `rknn-llm` 多模态示例使用同样的 RKNN 视觉编码器 + RKLLM 组合；本项目的 ABI 调用按该示例的 `image_enc` 和 `rkllm.h` 结构实现。参考：[Rockchip rknn-llm multimodal model demo](https://github.com/airockchip/rknn-llm/tree/main/examples/multimodal_model_demo)。

Demo 首版使用二进制 PPM，避免把 OpenCV 或其他图像库强行加入目标板依赖。Qwen3-VL-2B 视觉模型原生输入属性可能是 FP16，Demo 按参考实现提交 RGB UINT8 图像字节，由 RKNN runtime 转换。JPEG/PNG 可以先用已有 FFmpeg 转换：

```bash
ffmpeg -i input.jpg -frames:v 1 -pix_fmt rgb24 input.ppm
```

然后在目标板或交叉编译产物目录运行：

```bash
./edgesight_qwen_vl_demo \
  input.ppm \
  /path/to/qwen3-vl-2b-vision_rk3588.rknn \
  /path/to/qwen3-vl-2b-instruct_w8a8_rk3588.rkllm \
  '请描述图片中的主要内容。' 128 4096 0
```

参数最后一位是 RKNN 核数：`0` 使用自动调度，`1/2/3` 选择显式核数。Demo 会输出视觉编码器和语言模型耗时，并在模型/运行库缺失时返回非零退出码和具体路径诊断。它仍是独立 CLI，不会启动摄像头、推流或音频监听。

目标板实测的 Qwen3-VL-2B 单图运行时为 `rkllm-runtime 1.2.3`，视觉编码约 2.11 秒、语言阶段约 9.94 秒、峰值内存约 3.11GB；4B 方案延后到 16GB 及以上设备。

目标板部署后，可先做不加载模型的动态链接预检：

```bash
scripts/vision_preflight.sh \
  ./edgesight_qwen_vl_demo input.ppm \
  ./models/qwen3-vl-2b-vision_rk3588.rknn \
  ./models/qwen3-vl-2b-instruct_w8a8_rk3588.rkllm \
  ./lib
```
